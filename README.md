# AidMap

**University discovery and financial-aid planning for international applicants.**

[Explore AidMap](https://aidmap-aiaryskaliden.vercel.app/) · [Developer profile](https://github.com/aiaryskaliden)

## About

AidMap is a web project created to make researching universities less fragmented. The goal is to help applicants explore their options, compare admission information, and think through funding before building an application shortlist.

## Focus areas

- **University discovery:** explore universities and narrow down possible choices.
- **Comparison:** bring important application details together for side-by-side review.
- **Funding planning:** explore financial-aid possibilities and different cost scenarios.
- **Application organization:** make it easier to track and review a shortlist.

The website is the primary way to explore the project. Features and data are subject to change.

## Data and limitations

University policies, admission requirements, costs, scholarships and deadlines can change. Information shown by AidMap is intended for research and planning, **not** as an official decision, aid offer, admission guarantee or substitute for a university's own website. Always confirm details with the institution.
