# AidMap roadmap

The [150-university research record](research/CATALOGUE_150.md) describes the current catalogue. The next research pass prioritizes annual costs and Fall 2027 deadlines.

- Confirm missing Fall 2027 documents, English requirements and dated admissions rounds. Use the [coverage snapshot](DATA_REVIEW.md) and newer research notes to prioritize source checks.
- Add complete, dated cost breakdowns. Record tuition separately from living expenses and individual awards.
- Broaden less-selective US options and affordable European programmes with official undergraduate evidence.
- Manually review source URLs with access limits/timeouts; rerun link checks when sources change. Editorial verification remains necessary even when a link returns HTTP 200.
- Conduct real-device, Safari, Firefox, screen-reader and formal contrast testing with students. Current automated coverage uses Chromium at three viewport sizes.
- Add an editor-facing evidence workflow and expand citizenship- and qualification-specific matching where structured evidence supports it. Evaluate opt-in deadline reminders alongside the existing calendar export.
- Extend localization route by route. Evaluate privacy, migration and conflict resolution before adding cloud sync.
- Use the [Preview release procedure](VERCEL_PREVIEW.md) for public releases.

The planner does not submit applications, upload documents or send notifications. Application and scholarship decisions remain with institutions.
