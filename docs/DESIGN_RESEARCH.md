# UX research and original direction

Official pages reviewed during initial implementation. This was a text/structure review; JavaScript-only experiences were not treated as fully inspected visual interfaces.

| Reference                                                                     | Observed pattern                                                                                       | AidMap decision                                                                                                             |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [BigFuture college search](https://bigfuture.collegeboard.org/college-search) | The public response requires JavaScript; its full interactive UX was not available in the text review. | Keep university discovery central, without claiming detailed inspection of inaccessible controls.                           |
| [Common App Explore](https://www.commonapp.org/explore/)                      | Search, geography/financial-aid filters, result count, sorting and alternative result views.           | Persistent public filter URLs, sidebar groups, result count and grid/list views.                                            |
| [Studyportals for students](https://studyportals.com/for-students/)           | Organizes discovery by degree level and study direction.                                               | An explicit undergraduate/Fall 2027 scope, subject search and room in the schema for other countries.                       |
| [Niche Compare](https://www.niche.com/colleges/compare/)                      | Up to four colleges presented side by side.                                                            | Four-column comparison centered on evidence, requirements, cost uncertainty and aid terms. No rankings or admission scores. |
| [CSS Profile](https://cssprofile.collegeboard.org/)                           | A specific financial aid application process.                                                          | Explain it only where institution-specific instructions support it; never apply one generic checklist to all universities.  |
| [EducationUSA](https://educationusa.state.gov/)                               | A staged study journey spanning research, financing, application and preparation.                      | Discover → understand funding → plan; plain explanations for first-generation applicants.                                   |
| [Linear](https://linear.app/)                                                 | Clear product navigation and task-oriented organization.                                               | Quiet interface, consistent controls, compact status views and a useful workspace.                                          |
| [Vercel](https://vercel.com/)                                                 | Strong typography and clear navigation hierarchy.                                                      | Restrained type, source transparency and a consistent application shell.                                                    |

AidMap's original identity uses a compass wordmark, cobalt action color, navy text, pale slate surfaces, and teal evidence labels. The homepage route illustration is built in SVG/CSS and connects real profile links to planning; no university logos, photos, testimonials or invented success totals are used.

The funding chart only renders meaningful entered costs. Decorative charts, fake progress, inert buttons and implied integrations are intentionally absent. Mobile filters collapse, comparison/board regions scroll internally, forms retain explicit labels and keyboard controls, and motion respects user preferences.
