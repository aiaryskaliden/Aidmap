# AidMap application studio

Open /studio to work on your profile, essays, activities and university requirements. Maple is available at /advisor, with a link from profiles for a specific university. The studio can use the English, Russian or Kazakh interface. Maple uses the language of the question when it can detect it.

- **Overview** groups preparation by application system. UCAS, University of California, Common App and MIT each open a six-step checklist from the home page and the Apply menu. A card shows the percentage of steps marked complete for that system and entry year. Changing an item updates the card, and the existing workspace backup includes those marks. Use the official portal linked from the checklist to submit an application.
- **Getting started** tracks the applicant details, university list, intended major, grades, activities and essay drafts saved in AidMap. The planner section shows tracked deadlines. Each saved university also has its own tasks and documents, independent of the four preparation checklists.
- **My List** at `/my-list` uses the same saved universities as Explore and Planner. Choose a group on any card, or choose Automatic to use the available admissions and profile evidence. The published admission or offer rate includes its cohort. Profile checks show how many comparable requirements your profile meets. A manually assigned group is saved with the university and included in workspace backups.

- The profile uses the same academic preferences as Find my fit. Import a CV, review detected SAT, ACT, IELTS and GPA values, and save the fields you want to use.
- Essays can be written in the studio, pasted or imported. Drafts can be linked to an AidMap university and have an optional essay prompt and editable word limit. The preliminary rubric looks at prompt wording, concrete details, reflection, structure and length. Its feedback shows passages from the draft when available.
- Activities show an estimated tier from S to C− with eight levels. The editor explains the assigned tier using the applicant’s contribution, outcome, reach and evidence. The activity guide defines each level. Reach is optional and existing activity records work as saved.
- University fit checks programme match, test evidence, budget, deadlines and application materials. It identifies unknowns and links to published sources. Admission probability is unavailable from this method.
- PDF, DOCX, TXT and Markdown import reads text in the browser. The limits are 5 MB, 24 PDF pages and 30,000 extracted characters. A scanned PDF needs a text layer, or the text can be pasted separately.
- The local workspace stores extracted text and file names in this browser. Backups exported from Preferences include the locally saved material. Advisor and the Groq demo have no access to the original files, private essay drafts, or activity descriptions. See the [Advisor guide](AI_ADVISOR.md) for the opt-in profile fields and demo behavior.
- **Honors & achievements** keeps formal awards and personal outcomes together. Each entry can include multiple levels of recognition, grades, the date, the awarding body or project, and details. Both collections are stored in the browser and included in workspace backups.
