# AidMap 2.0 — результат работы

20 октября 2026 года. Изменён существующий проект AidMap. Исходная версия сохранена локальным Git-коммитом `1335cba`. Другие проекты не менялись. Новая версия не опубликована.

## A. Реализованные изменения

- `/explore`: быстрые и расширенные фильтры, отдельные SAT/ACT и варианты подтверждения английского, реальные undergraduate-направления, страны, funding, application rounds, период дедлайна, fees и источник данных. Выбор хранится в URL; доступны удаление отдельных условий и полный сброс. На мобильном — диалог с Escape и возвратом фокуса.
- `/universities/[slug]`: 30 профилей, требования и ограничения программ, документы, платформы и сборы, отдельные условия scholarships, стоимость с учебным годом и исключениями, таблица дат, ссылки на источники рядом с утверждениями. Дополнительные сведения раскрываются по запросу.
- `/`: категории Europe, Business и full tuition ведут к реальным подходящим записям; число вариантов рассчитывается из каталога.
- `/start`: необязательные четыре шага знакомства с продуктом, пропуск шагов, сохранение предпочтений, объяснение исследовательских совпадений.
- `/calculator`: исправлены AM-004/AM-005, сохранены раздельные подтверждённые и гипотетические суммы; неизвестные значения не подменяются нулём.
- `/compare`: SAT/English, проверенные даты, годы опубликованных расходов и предупреждения об их несопоставимости.
- `/planner`: задания со ссылками на источники, подтверждённый перенос подходящей даты с сохранением источника; изменение вручную переводит дату в пользовательскую. Существующие статусы, задачи и заметки сохранены.
- `/dashboard`: реальные показатели стадий и задач, предстоящие проверенные даты, отдельные сведения о неподтверждённых дедлайнах.
- `/profile`: совместимые JSON/CSV, выбор шкалы TOEFL 120 или 6 без выдуманного пересчёта; сохранена защита повреждённых данных.
- Общие подсказки объясняют need-blind, full need, full tuition/full cost, тесты, раунды, сроки и funding gap. Увеличены основные и второстепенные тексты, исправлено переполнение при увеличении масштаба.

| Проблема | Решение / результат |

| AM-005: неправильный вклад скрывал корректные расходы | Валидация вклада отделена от расчёта расходов. Total и remaining cost остаются видимыми; gap неизвестен, ошибка показана, сохранение заблокировано. |

| Исторические даты выглядели пригодными для планирования | Проверяются intake, точный год, источник и наступление даты. Перенос требует явного подтверждения. |
| Требования английского могли относиться к другой программе или scholarship | Добавлена область применения; такие сведения не используются как общие требования поступления. |
| Переполнение при 200% масштабе | Перенос элементов шапки/подвала и длинных кнопок; встроенные таблицы прокручиваются внутри своего блока. |
| U01: возможная потеря пользовательской даты | В тестах не воспроизвелась: дата проверена после навигации, обновления страницы и экспорта/восстановления. Неподтверждённую причину не выдумывали. |
| U02: возможная проблема резервной копии | Проверены реальные скачанные JSON/CSV, полное сравнение восстановленного JSON и сохранение данных при невалидном импорте. Воспроизводимой потери не найдено. |

## C. Логика требований

Между группами используется AND, внутри группы — OR. Например, страна и направление должны совпасть вместе, но IELTS или TOEFL могут быть альтернативами. Результат отдельного условия — совпадение, несовпадение либо неизвестно. Неизвестные варианты показаны отдельным количеством и доступны через переключатель; известные несовпадения не возвращаются при его включении.

SAT required, optional, not accepted, flexible и unknown моделируются отдельно. Минимум, рекомендация, медиана и middle-50% не смешиваются. Низкий относительно медианы балл не означает автоматический отказ или невозможность подачи. Гражданство, программа, язык обучения, год и правила scholarship требуют проверки условий; сайт не обещает поступление или финансирование.

Economics не автоматически становится Business. В каталог попадают документированные бакалаврские программы, а не MBA. Стоимость сравнивается только в одной валюте; старый опубликованный год сохраняется. Пустые поля не превращаются в нули.

## E. Источники и пробелы

Источники и даты проверки сохранены в `research-universities.json` и `data/research-*-v2.json`. Нормализация находится в `data/universities.ts`. Проверка 152 уникальных URL дала 129 успешных HTTP-ответов, один 404 и 22 результата, требующих ручной проверки (ограничение доступа, timeout, иные ответы). HTTP 200 сам по себе не подтверждает содержание.

Удалённая брошюра Amherst заменена актуальной страницей с честным unknown для неподтверждённой merit policy. Для исторического PDF Swarthmore получен 404; merit eligibility теперь unknown, исходный URL и причина сохранены для ручного исследования. Для Princeton остаётся конфликт в таблице aid deadlines. У многих вузов ещё нет подтверждённых текущих документов, English policy, дат или полного бюджета. Ограничения EEA/non-EU, sending partners, конкретных программ и renewal показаны в тексте awards.

Подробная таблица по каждому вузу и все проблемные URL: [DATA_REVIEW.md](DATA_REVIEW.md). Машиночитаемый результат: [DATA_REVIEW.json](DATA_REVIEW.json). Методология: [DATA_METHODOLOGY.md](DATA_METHODOLOGY.md).

## H. Локальный запуск

В папке AidMap, Node 24 и pnpm 11.25:

```powershell
pnpm install --frozen-lockfile
pnpm dev --webpack
```

Адрес: http://127.0.0.1:3000. Для проверки готовой сборки остановить dev, затем:

```powershell
pnpm build
pnpm start
```

Не запускать оба сервера одновременно на одном порту.
